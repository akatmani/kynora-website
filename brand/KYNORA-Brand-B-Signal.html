02 — Concept

The dot is the moment people start talking.

The signal

The o is a solid dot: a light switching on, a record, a full stop on a launch. It is the only element that is always Vermilion.

Lowercase

Lowercase feels like a person talking, not a company announcing. Warm, direct, a little bold.

The dot travels

The same dot turns up as a live status, a play button, a sticker and a bullet. Seeing it anywhere should mean KYNORA.

05 — Construction

Set once, then locked.

01The dot is 1.04× the x-height, so it reads optically the same size as the letters.
02It sits on the baseline with a 1% overshoot, like any round letter.
03Tracking is −3.5% and set by the file: never re-type the logo.
04Vermilion dot on every version except one-colour print.

Always use the master artwork files. The logo is never re-typed or redrawn.

10 — Colour in use

Mostly Ivory. A little red goes a long way.

Ivory 46%Carbon 24%Vermilion 16%Blush 8%Stone 6%

Vermilion is the signal, so it only works if it is rare. One Vermilion moment per screen or page: a button, a logo accent, a highlight. For small text or links on Ivory use Brick: same family, readable.
